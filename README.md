# Rime 主题工坊（离线单文件版）

可视化制作 Rime 输入法主题的在线工具的离线副本，一个 HTML 文件包含全部功能，可离线使用。

## ✨ 功能

- 可视化编辑 Rime 主题全套参数（颜色、字体、字号、间距、圆角、阴影、透明度、毛玻璃模糊）
- 十余种预设配色（五笔小筑、暮霭、松烟、水墨、远山/Nord、青花 等）
- 亮色 / 暗色 / 跟随系统三种模式
- 导入已有 YAML；导出 `squirrel.custom.yaml`（鼠须管 macOS）/ `weasel.custom.yaml`（小狼毫 Windows）
- 编辑进度自动保存在浏览器本地

## 🚀 使用

直接用浏览器打开 `index.html` 即可，无需联网、无需安装任何东西。

在线访问地址：`https://<你的GitHub用户名>.github.io/<仓库名>/`
